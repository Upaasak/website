POWER SYSTEM PROTOCOLS

TOP MODULE ▸ ipdft_channel_top

A six-channel interpolated-DFT front end for grid instrumentation. Each channel windows its input, runs a sliding DFT bin, extracts magnitude and phase with a CORDIC, and differentiates frequency to get ROCOF. One clock domain, fixed point throughout, no vendor IP.

It exists because a commercial PMU front end costs more than the lab's annual budget, and because it is a good excuse to learn where a fixed-point error budget goes wrong.

STAGE 1
WINDOW

Hann coefficients in a single BRAM, shared across channels by time multiplexing. Q1.15 in, Q2.30 out, truncation error bounded at 2⁻¹⁴.

STAGE 2
SLIDING DFT BIN

Recursive bin update with leakage damping, five bins per channel. Guard bits sized from the worst-case input rather than from optimism.

STAGE 3
CORDIC MAG / PHASE

16-iteration vectoring CORDIC, one shared engine, arctan table in ROM. Gain compensated at the output, not per iteration.

STAGE 4
IPDFT CORRECTION

Three-point interpolation over neighbouring bins to recover off-bin frequency, then a differentiator for ROCOF with a configurable window.
