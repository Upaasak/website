THE MASTERMIND

SECOND BRAIN · THE HUB OF ALL THINGS

Every other sb-proj-* repository is a code satellite: the RTL, tests and bitstreams of one project. This one holds no code. It holds the knowledge: every project's status, every reusable module, every hard-won bug fix, every architecture decision, each linking out to the code it describes.

It is the hub. The code repos are the spokes.
